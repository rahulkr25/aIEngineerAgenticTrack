# Day 3 — Models, APIs & Evaluation

Course notes: model comparison, API integration, client libraries, and evaluating AI responses.

---

## Model Comparison

The course covers various large language models (LLMs)—GPT-4, Claude, Gemini, DeepSeek—their strengths and the trade-offs between paid APIs and open-source models. Choosing the right model depends on project requirements.

---

## API Integration

Content includes integrating multiple APIs (e.g., OpenAI, Anthropic), managing state in client-side applications with frameworks like LangChain, and techniques to reduce vendor lock-in.

---

## LLM Client Libraries

Different client libraries are used to call LLMs; the OpenAI Client Library is emphasized. Running local models and calling cloud-hosted models efficiently supports varied workflows.

---

## Evaluating AI Responses

Evaluating AI-generated responses is emphasized: comparing outputs across models helps select the best option for a given use case and improves accuracy.
